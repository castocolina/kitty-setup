### Key Patterns Discovered

- Plan execution only works **sequentially in the primary checkout**: worktree-isolated agents may
  not set `HOME` (scratch-HOME runs refused), and the harness auto-deletes an unchanged worktree
  together with its gitignored `tmp/` evidence. Hence `workflow.use_worktrees: false`. Note that
  every `gsd-tools query dispatch-isolation` call re-records the isolation sentinel.
- Shell rule from the user: one plain command per Bash call; anything with `cd`, redirections,
  `tee`, heredocs, chains, loops or variables goes into a `.sh` written with Write and run as
  `bash <path>`. Every subagent brief must repeat it.
- Review lanes: probe first (`echo 'Reply with exactly: OK' | timeout 90 opencode run --model
  'router-env/my-referee-one#high' -`), fall back to `my-referee-three`. Only `#high` is accepted;
  `#xhigh`/`#max` fail ("Variant unavailable").
- Executors may amend an **unpushed** RED commit to fix their own RED-test lint; nothing else.
