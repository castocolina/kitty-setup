where "doctor exits 0 with every check PASS or SKIP" becomes a measured fact rather than a plan.

`register-python-argcomplete --shell bash` and `--shell zsh` emit **byte-identical** output, so the
shell distinction is not about the file; and zsh needs `compinit` to have run **before** our source
line or every shell start prints `command not found: compdef`. The second one is what forces
`_BLOCK_BODY_LINES` — today a module-level `Final[tuple[str, ...]]` — to become a function of the
shell.
