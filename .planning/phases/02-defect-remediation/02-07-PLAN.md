<objective>
Delete a dead feature and make the install report say what actually happened (D-11, D-13).

Purpose: three small untruths in one file. `_record_install_log` writes a file nothing reads — it exists
only because a now-frozen spec asked for it. `_print_path_result` prints "appended block to …" for every
change, discarding the four changed-branch reasons `path_integration` computed one function call earlier, including
"migrated legacy marker" and "removed duplicate legacy marker" which are exactly the cases a user would
want to see named. And the unsupported-shell hint prints one line where the result now carries more.

Vulture found the second defect independently — `path_integration.py:58: unused variable 'reason'` — so
fixing D-13 here removes one R0.11 finding before `02-09` runs. That is the whole reason R0.11 is
scheduled last.

where the log lands and that nothing reads it; a RED commit holding the tombstone cases and the report
cases, proven failing from its own tree; then `_record_install_log` gone, `_print_path_result` reporting
the real reason and every hint line, and the confirmation that `_repo_root` survives with two callers.
</objective>
