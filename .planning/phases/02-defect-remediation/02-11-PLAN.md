<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the compositor's exit status → the gate's verdict | The compositor sits between pytest and the caller. Its status is not pytest's by any contract, so trusting it would let a wrapper decide pass or fail on the tests' behalf. |
| the developer's environment → the child inside the compositor | Display and kitty remote-control variables, and the controlling terminal, would otherwise let an integration test reach the user's live kitty session. |
| the runner's process group → the host after the run | Anything the run spawns and does not reap is left on the user's machine. |
| `PYTEST_ARGS` → pytest's argv | A developer-supplied selector crosses into a subprocess argv. It is never given to a shell. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-2-43 | Repudiation | a wrapper whose exit status replaces pytest's | high | mitigate | The verdict is read from a status file the child writes. The compositor's status is never returned. A fake compositor that always exits 0 is a unit case, and every gate over the runner asserts pytest's own `N passed` and the absence of `failed\|error` in captured output. |
| T-2-44 | Repudiation | a run that did not happen reported as green | high | mitigate | No compositor, no usable `XDG_RUNTIME_DIR`, a missing status file and a timeout each exit non-zero (69 or 70) with a message saying the suite was NOT run. A real-host gate runs the target with a `PATH` lacking cage and requires a non-zero exit, the message, and no passing count. |
| T-2-45 | Information Disclosure / Tampering | an integration test reaching the user's live kitty through inherited `KITTY_LISTEN_ON`/`KITTY_WINDOW_ID` or `/dev/tty` | medium | mitigate | The display and kitty remote-control variables are scrubbed, stdin is detached, and the compositor starts in a new session with no controlling terminal. Measured: the full suite passes under exactly these settings. |
