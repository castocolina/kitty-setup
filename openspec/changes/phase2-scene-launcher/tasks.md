## 2. Module `src/kitty_setup/scenes/launcher.py`

- [x] 2.1 Create `src/kitty_setup/scenes/launcher.py`. Top-of-file docstring SHALL cite Phase 2 §12, mention the h25 probe at `tmp/h25-scene-launcher/`, and note that the module composes the existing scene primitives via raw `_client.kitten_at()` calls (NOT by importing `title.py` / `accent.py` / etc. — confirms spec scenario "Module imports only from `_client` and stdlib").
- [x] 2.2 Define a frozen `@dataclass Pane` with fields `title: str | None = None`, `cmd: str | None = None`, `cwd: str | None = None`, `bg: str | None = None`.
- [x] 2.3 Implement `parse_pane_spec(s: str) -> Pane` as a hand-written state machine per `design.md` D2: walks characters, treats `\,` as literal comma and `\\` as literal backslash, splits on bare commas, then splits each segment on the FIRST `=` only (value side may contain `=`). Recognised keys: `title`, `cmd`, `cwd`, `bg`. An empty value (e.g. `title=`) SHALL be stored as `None`, NOT as `""` — `Pane` field semantics are exactly "absent (None) → omit the corresponding kitten flag" vs "present (str) → emit the flag". This keeps the `launch_scene` guard expressible as `if p.title is not None` without ambiguity. Raises a clear `ValueError` on: empty input, no `=` in a segment, duplicate key, unknown key, trailing comma.
- [x] 2.4 Implement `launch_scene(layout: str | None, tab_title: str | None, tab_accent: str | None, panes: list[Pane], *, to: str | None = None) -> int`. Follows the kitten call algorithm from `design.md` D3 exactly: tab launch + first pane bg + goto-layout + per-additional-pane launch/bg + tab accent. Captures the window id from each `launch` stdout via `int(result.stdout.strip())`. Fails hard on `launch` non-zero exits (propagates exit code, stops processing); fails soft on `set-colors` / `set-tab-color` (prints stderr to `sys.stderr`, records the exit code, continues). Returns the first non-zero exit code (or 0 if all calls succeed).
- [x] 2.5 Wrap every user-supplied `cmd` as `["bash", "-lc", cmd]` when passed to `kitten_at("launch", ..., "bash", "-lc", cmd)`. Always pass `--hold` per `design.md` D3.
- [x] 2.6 Implement `cli_scene_launch(args: argparse.Namespace) -> int`. Parses each string in `args.panes` via `parse_pane_spec`. On `ValueError`, prints a clear stderr message and returns 1. On zero panes (`len(args.panes) == 0`), prints stderr "scene launch requires at least one --pane" and returns 1. Otherwise calls `launch_scene(args.layout, args.tab_title, args.tab_accent, parsed_panes, to=args.to)` and returns its exit code.
